# Gramterm

**Telegram в терминале — быстро и по-человечески.**

Gramterm — TUI-клиент Telegram на Rust. Цели: низкий порог входа, Simple-режим по умолчанию, мышь, русский язык, passcode и приватность без компромиссов.

> **Статус:** Phase 0 — каркас TUI и demo-режим. TDLib-бэкенд подключается на следующем этапе.

## Возможности Phase 0

- двухпанельный интерфейс: чаты, история, композер, статус-бар;
- demo-режим с фейковыми чатами и сообщениями;
- Simple-режим: стрелки, Tab, Enter, мышь;
- Vim-режим: `hjkl`, `i`, `Esc` (переключается командой `:vim` / `:simple`);
- клики по чатам, колесо мыши, фокус композера;
- RU/EN интерфейс;
- темы `mocha` / `latte`;
- `?` — помощь, `:` — команды, `F2` — отпустить мышь для выделения текста;
- без телеметрии.

## Запуск

Нужен Rust 1.88+.

```bash
cargo run -- --demo
```

Флаги:

```text
--demo            demo-режим без Telegram
--lang ru|en      язык интерфейса
--theme mocha|latte
--no-mouse        не захватывать мышь
```

## Клавиши

| Клавиша | Действие |
|---|---|
| `↑` / `↓`, `j` / `k` | движение по чатам/сообщениям |
| `Tab` / `Shift+Tab` | переключение фокуса |
| `Enter` | открыть чат / отправить |
| `i` | фокус в композер |
| `Esc` | назад / закрыть попап |
| `?` | помощь |
| `:` | команда |
| `F2` | отпустить/захватить мышь |
| `Ctrl+C` | выход |
| `q` | выход |

Команды: `:demo`, `:lang ru`, `:lang en`, `:theme mocha`, `:theme latte`, `:simple`, `:vim`, `:quit`.
